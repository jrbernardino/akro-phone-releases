# AKRO Phone - releases

Instaladores de AKRO Phone (softphone para AKRO BPO, basado en MicroSIP).
El codigo fuente se mantiene en un repositorio privado; este repositorio solo
publica los instaladores que usan las PCs para actualizarse.

- Descargar la ultima version: seccion **Releases** -> `AKRO-Phone-Setup-<version>.exe`.
- `latest.json` en cada release: version, URL y SHA-256 del instalador. Lo lee
  el actualizador automatico instalado junto con la aplicacion.

Los releases se publican automaticamente desde GitHub Actions; no subir
archivos a mano.
